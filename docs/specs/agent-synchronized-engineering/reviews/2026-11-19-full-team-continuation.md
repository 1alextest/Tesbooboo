## What this continuation makes concrete

The proposal gives Skill-governed AI a bounded reasoning role over permitted native graph and document evidence. It can interpret an obligation, trace a conditional consequence, suggest a missing test or relationship, compare alternatives, and return a justified no-effect or unknown outcome. The service still owns identity, scope, schema, permissions, immutable versions, calculation, execution receipts and protected writes. A Skill can change supported reasoning behavior without a code deployment for every heuristic; a missing capability or authorization still requires its actual owner to provide it.

The same ownership model covers code-free requirements, policies, manuals, native cases and real execution evidence. Graph Analytics remains in Reports. Model Studio retains model applicability; native Cases, Runs, Bugs, KB, proposal/review and source-history owners retain their records. T-422 owns method composition and assignment. No competing graph, case, runner, metric, policy-decision or approval store is justified merely by an AI feature name.

The original QA loop remains explicit: a task can reach the assigned external installation and its own driver without first manufacturing a test case; its original report survives analysis, linked retest and exact human-selected native apply. Ordinary human manual QA remains valid without code, a formal model or an automated driver. Preparing a Run, selecting a path, approving a model and observing an actual target result remain different events.

The final specifications now connect these distinctions to concrete source paths, existing task IDs and discriminating acceptance conditions. Semantic consequences include independently applicable conflicting obligations, necessary guards, historical/current/future effectivity, meaningful missing links versus lexical decoys, and safe invalidation of dependent candidates after a correction. The five diagnostic labels are mapped into existing obligations; their origin remains the [informed author diagnostic](2026-11-20-semantic-skill-diagnostic.md), not a new cold discovery or runtime result.
