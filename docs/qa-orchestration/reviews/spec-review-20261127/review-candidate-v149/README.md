# Original-receipt link compatibility

`INPUTS.json` is the byte-identical C1 manifest retained at this path so the original Red A receipt's workspace-relative link remains usable after publication. The canonical review index and reconstruction receipt are one directory above. This is immutable review metadata, not another specification owner or active candidate. C1 artifact bytes are reproducible by reversing `candidate-c1-to-c2.patch` against the exact C2 inputs; `c1-reconstruction.json` records the verified 13/13 identity match.
