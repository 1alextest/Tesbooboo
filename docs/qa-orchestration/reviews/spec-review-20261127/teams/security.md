## Source observations that remain gates, not newly discovered defects

1. **Disconnect is not data revocation.** Current `integrationDisconnect` clears credentials and disables mappings while intentionally retaining visible knowledge. This is actual current behavior, not evidence of a new leak introduced by C1. Before admitting a profile whose upstream grants restrict retained data, its source/knowledge owners must settle retention and revocation semantics and prove them through ordinary reads, search, version history, RAG, caches and exports. C01 item 5, C03:2141, C04:1280 and C05's historical-result scenario already require this. Do not implement a destructive purge or retroactively hide legitimate native history merely from the word “disconnect.”
2. **Current provider lookup is not immutable source-generation binding.** The worker loads by organization/provider both for coordination and later document work (`processor.ts:162–175,481–498`), and the mirror key omits an account namespace (`538–598`). This supports the candidate's convergence gate; it does not establish a deployed collision. Qualification must include sequential account rebinding and delayed events as well as two simultaneously admitted sources. The candidate's configure/connect and general stale-generation requirements already cover that consequence; the multi-source example alone must not be used as its entire proof.
3. **Current entry checks and diagnostics are narrower than a plugin security substrate.** The request gateway, native transaction authority, trace masking and project-scoped retrieval are reusable controls with different grain. They do not prove arbitrary package confinement, every queued callback fence, independent workload identity, source-wide revocation or protected telemetry custody. Prior C03:1984–1997 explicitly makes this maturity distinction, so C1's “reuse” is read as retaining/extending those owners, not declaring the new guarantees built.

These are material acceptance limits, not accepted residual risks or requests to widen the present task. No unrelated source security issue was sufficiently investigated to assert a side finding.
